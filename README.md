#PROJECT TECHNIQUE CYBERSÉCURITÉ
ESI 5-26 CS ISI RENNES
##Projet Cybersécurité : Supervision et analyse réseau
Dans le cadre de ce projet, vous devez concevoir et réaliser un outil de supervision et d’analyse réseau dont
vous êtes libres de choisir le nom, permettant d’observer et d’analyser un réseau informatique, de mapper un
réseau informatique, détecter les événements suspects, de générer des alertes et d’exporter des rapports.
##L’objectif est de développer un outil capable de :
1. Détecter les équipements connectés au réseau ;
2. Scanner une plage d’adresses IP ;
3. Identifier les ports ouverts ;
4. Récupérer des informations sur les services réseau ;
5. Observer le trafic réseau ;
6. Détecter des comportements suspects ou malveillants ;
7. Générer des alertes ;
8. Produire des rapports exportables en JSON ou CSV.
##Contraintes techniques :
1. Backend : Python, avec FastAPI et les bibliothèques nécessaires au cœur fonctionnel de l’outil.
2. Frontend : HTML, CSS, JavaScript, avec utilisation possible de Bootstrap ou Tailwind CSS.
##Le projet devra montrer votre capacité à :
1. Concevoir une solution technique cohérente ;
2. Développer un outil orienté cybersécurité ;
3. Travailler en équipe ;
4. Organiser un projet de manière professionnelle ;
5. Présenter et défendre votre solution.
##Livrables attendus
1. Dépôt GitHub propre et structuré contenant l’intégralité du code source du projet, avec un versioning
clair, des commits réguliers et explicites, ainsi qu’un README présentant l’outil et précisant
l’installation et l’utilisation de la solution.
2. Une release GitHub correspondant à la version finale, fonctionnelle et facilement testable du projet.
3. Support de présentation au format PPT ou PDF, clair, structuré et paginé, accompagné d’une
soutenance avec démonstration.
